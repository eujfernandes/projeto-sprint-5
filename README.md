# Análise de Vendas de Carros

Este projeto é um aplicativo web interativo desenvolvido com **Streamlit**, que permite analisar visualmente um conjunto de dados de vendas de carros usados. O objetivo é facilitar a exploração de dados como preço e quilometragem, ajudando usuários a entender melhor o mercado de veículos usados.

## Funcionalidades

- Visualização interativa com **Plotly**
- Filtro deslizante para limitar a análise por **faixa de preço**
- Gráfico de **histograma** da quilometragem dos veículos
- Gráfico de **dispersão** entre quilometragem e preço
- Interface amigável com seleção de tipo de gráfico (via botão de rádio)
